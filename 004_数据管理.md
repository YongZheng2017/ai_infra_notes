## 数据集格式

```
from datasets import load_dataset

dataset = load_dataset("stanfordnlp/imdb", split="train")

dataset.to_csv("imdb_train.csv")
dataset.to_json("imdb_train.json")
dataset.to_parquet("imdb_train.parquet")
```

|         |       |            |                                                      |
| ------- | ----- | ---------- | ---------------------------------------------------- |
| Format  | Size  | Read Speed | Best For                                             |
| CSV     | Large | Slow       | Human readability, spreadsheets                      |
| JSON    | Large | Slow       | APIs, nested data                                    |
| Parquet | Small | Fast       | Analytics, columnar queries                          |
| Arrow   | Small | Fastest    | In-memory processing (what datasets uses internally) |

## 数据集拆分

Every ML project needs three splits:

- Train: The model learns from this (typically 80%)
- Validation: You check progress during training (typically 10%)
- Test: Final evaluation after training is done (typically 10%)

```
from datasets import load_dataset

dataset = load_dataset("stanfordnlp/imdb", split="train")

split = dataset.train_test_split(test_size=0.2, seed=42)
train_val = split["train"].train_test_split(test_size=0.125, seed=42)

train_ds = train_val["train"]
val_ds = train_val["test"]
test_ds = split["test"]

print(f"Train: {len(train_ds)}, Val: {len(val_ds)}, Test: {len(test_ds)}")
```

## DVC

data version control，DVC creates small .dvc files that point to your data. The data itself lives in S3, GCS, or another remote storage backend.

```
pip install dvc
pip install "dvc[s3]"

// 进入git 项目
dvc init

dvc remote modify data endpointurl http://127.0.0.1:3900
dvc remote add -d dvcdata s3://my-bucket/dvc-store
dvc add testdata  // 增加文件跟踪
dvc push
```

## 本地搭建S3服务

安装 Garage

```
wget https://garagehq.deuxfleurs.fr/_releases/v1.1.0/x86_64-unknown-linux-musl/garage -O /tmp/garage
sudo mv /tmp/garage /usr/local/bin/garage
sudo chmod +x /usr/local/bin/garage

garage --version    // garage v2.0.0 [features: k2v, ...]


sudo useradd --system --no-create-home --shell /bin/false garage
sudo mkdir -p /data/garage/data /data/garage/meta /etc/garage
sudo chown -R garage:garage /data/garage /etc/garage

// 配置
openssl rand -hex 32  // 49fa2fb63b37509e44180c7f0048fcfd09c452ff28a793acf0c8f65cee6faf06
sudo nano /etc/garage/garage.toml
sudo nano /etc/systemd/system/garage.service

// 启动
sudo systemctl daemon-reload
sudo systemctl enable --now garage
sudo systemctl status garage

// 分配存储容量
# 1. 查看节点 ID（记下输出的 Node ID，类似一段长哈希）
sudo -u garage garage -c /etc/garage/garage.toml status

# 2. 为节点分配存储容量（-z 指定区域名，-c 指定容量，可随意设置）
# 将 <你的NodeID> 替换为上一步获取的 ID
sudo -u garage garage -c /etc/garage/garage.toml layout assign -z dc1 -c 100G <你的NodeID>

# 3. 应用布局变更
sudo -u garage garage -c /etc/garage/garage.toml layout apply --version 1

# 4. 再次检查状态，应显示 Healthy
sudo -u garage garage -c /etc/garage/garage.toml status

sudo -u garage garage -c /etc/garage/garage.toml key create my-app-key
sudo -u garage garage -c /etc/garage/garage.toml bucket create my-bucket
sudo -u garage garage -c /etc/garage/garage.toml bucket allow --read --write --owner my-bucket --key my-app-key

export AWS_ACCESS_KEY_ID="你的Key ID"
export AWS_SECRET_ACCESS_KEY="你的Secret Key"
export AWS_DEFAULT_REGION="garage"
```

garage.toml

```
metadata_dir = "/data/garage/meta"
data_dir = "/data/garage/data"
replication_factor = 1
consistency_mode = "consistent"

rpc_bind_addr = "0.0.0.0:3901"
rpc_secret = "xxx"

[s3_api]
api_bind_addr = "0.0.0.0:3900"
s3_region = "garage"

[admin]
api_bind_addr = "0.0.0.0:3903"
```

garage.service

```
[Unit]
Description=Garage S3-compatible object storage
After=network.target

[Service]
Type=simple
User=garage
Group=garage
ExecStart=/usr/local/bin/garage -c /etc/garage/garage.toml server
Restart=always
RestartSec=10
LimitNOFILE=1048576

[Install]
WantedBy=multi-user.target
```
