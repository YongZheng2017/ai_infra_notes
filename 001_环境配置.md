# 环境配置

## 四层环境

- System Foundation：OS, shell, git, editor, GPU drivers

- Package Managers：uv, pnpm, cargo, juliaup

- Language Runtimes：Python 3.12+, Node 22+, Rust, Julia

- AI/ML Libraries：PyTorch, JAX, transformers, etc.

&nbsp;

## WSL 安装 Ubuntu

机器：Windows 11

```
wsl --install -d Ubuntu-24.04
lsb_release -a  # 查看系统版本
sudo apt update && sudo apt install -y build-essential git curl wget  # 安装相应工具
```

&nbsp;

## 安装 Python with uv

```
curl -LsSf https://astral.sh/uv/install.sh | sh
uv python install 3.12

uv venv  # 创建虚拟环境
source .venv/bin/activate  # 激活虚环境  # or .venv\Scripts\activate on Windows

uv pip install numpy matplotlib jupyter
```

&nbsp;

## 安装 Node.js with pnpm

```
# curl -fsSL https://fnm.vercel.app/install | bash
# 上面地址访问失败时，使用下面备用镜像
curl -fsSL https://www.fnmnode.com/install.sh | bash
source /home/test/.bashrc
fnm install 22
fnm use 22

npm install -g pnpm
node -e "console.log('Node', process.version)"    // Node v22.23.2
```

&nbsp;

## 安装 Rust

```
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

rustc --version    // rustc 1.98.1 (48a229cea 2026-09-01)
cargo --version    // cargo 1.98.1 (797e8a9bc 2026-08-05)
```

## 设置 GPU 和 Pytorch

```
nvidia-smi    // NVIDIA GeForce RTX 3060    CUDA UMD Version: 13.4

uv pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu130
//  torch==2.14.0+cu130
```

&nbsp;

验证：verify.py

```
import torch
print(f"CUDA available: {torch.cuda.is_available()}")           # False on macOS — expected
print(f"MPS available:  {torch.backends.mps.is_available()}")   # True on Apple Silicon
if torch.cuda.is_available():
    print(f"GPU: {torch.cuda.get_device_name(0)}")
```
