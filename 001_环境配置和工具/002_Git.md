# Git

## 配置 git

```
git config --global user.name "Your Name"
git config --global user.email "you@example.com"

git config -l  // 查看配置
```

&nbsp;

## 配置 github

```
# ubuntu上执行
ssh-keygen -t ed25519 -C "your_email@example.com"    // 一路按回车，使用默认路径并可以设置一个密码（或留空）

cat ~/.ssh/id_ed25519.pub
// 复制输出的全部内容（以 ssh-ed25519 开头），登录 GitHub，进入 Settings -> SSH and GPG keys
// 点击 New SSH key，在 "Title" 中给这个密钥起个名，在 "Key" 中粘贴刚才复制的公钥内容，然后点击 Add SSH key。

ssh -T git@github.com  // 测试配置是否正确
// 成功的消息：Hi YongZheng2017! You've successfully authenticated...
```

## 日常工作流程

```
git clone git@github.com:YongZheng2017/ai_infra_notes.git  // 克隆项目
cd ai_infra_notes  // 进入项目目录


// 在dev分支上开发并提交
git checkout -b dev    // 创建并切换到dev分支
// 新增或修改代码后提交(例如新增 .gitignore)
git add .  // 增加改动的文件
git commit -m "新增 .gitignore"   // 提交
git push origin dev    // 将dev分支的改动推送到远程仓库


// 合并开发分支到主分支
git pull origin main    // 先在dev分支上尝试合并main分支
git status  // 查看状态，若有冲突，在dev分支解决冲突后提交并推送

// 切换到main分支，将dev分支的改动合并进来并推送到服务器
git checkout main
git merge dev
git push   // 推送到服务器

git log --oneline  // 查看日志
```
